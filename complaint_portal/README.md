# Student Complaint Portal (Flask + SQLite)

## Run
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

## Logins
- Admin: admin@college.edu / admin123  (change after first login/in code)
- Student: use the Register page

## Features
- Student register/login, submit complaints, track status & admin replies
- Admin dashboard: counts, filter by status/category, update status, reply
- Passwords hashed, SQLite DB (complaints.db) auto-created
